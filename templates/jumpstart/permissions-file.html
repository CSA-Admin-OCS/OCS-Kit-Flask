{% endcall %} {% call section("Writing a request") %}

"METHOD /route": one of GET, POST, PUT, PATCH or DELETE, one space, then the route exactly as Flask writes it, converters and all (/api/classrooms/<int:id>, /api/microblog/page/<string:page_key>). Things to know:

  • A trailing slash is part of the route: /api/classrooms/ and /api/classrooms are different entries, and an app route may exist in only one form.
  • A route that answers several methods needs one entry per method, and each may have a different level (GET /api/user is member, DELETE /api/user is admin).
  • HEAD is answered like GET; OPTIONS is never listed.
  • Some routes have aliases (/api/organization and its old address /api/school): each is its own entry.
  • To get the text right, copy it from the Permissions page, or from the message of the 403 an unlisted route answers.

Each message starts with permissions.json:. And against the app, python -m permissions --check reports "X is a route but is in no list" and "X is in the file but the app has no such route". Both are tests too.

So a change is a one-line difference in review, and two people adding different routes do not conflict. The tools that rewrite the file keep that format: entries sorted by route, then method, one per line.
