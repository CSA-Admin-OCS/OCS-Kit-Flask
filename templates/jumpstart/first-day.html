Python 3.10 or newer is needed. In development an unset password is 123Qwerty! and an unset SECRET_KEY becomes a random one, so every account is signed out at each restart; set a fixed one in .env to stay signed in. python scripts/db_init.py drops every table first and asks before doing so; on a folder with no database it has nothing to drop.

Restart after changing Python code. The development server does not reload itself, so a page can show new template changes with old route code until it is restarted.

{% endcall %} {% call section("Running with Docker") %} {% call code() %}cp .env.example .env # set ORG_NAME, SECRET_KEY, ADMIN_PASSWORD and DEFAULT_PASSWORD docker compose up -d --build{% endcall %}

The first boot creates the database by itself when there is none. The compose file also starts the socket service (port 8500) and the code runner. Data lives in instance/ on the host, so back that folder up. See {{ ref('deploy') }}.

{% endcall %} {% call section("Initial inspection as an administrator") %}

Sign in at /login, then open the Data menu:

  • User Management: every account; the Edit menu goes to the Roles page or Sections for that account.
  • Web Security: Permissions (who may make each request), CORS (which websites may call the backend) and Roles (the tiers L1 to L4).
  • The home page lists what is on, and the Q&A guide answers how to do each thing.
{% endcall %} {{ topic("Three safe changes") }} {% call section("Safe changes and how to revert them") %}
  1. Tighten a request. On the Permissions page, set GET /api/study (an unreviewed request, open to anyone) to the member level and Save. In another window, call it without signing in: it now answers 401. Press Reset and it is open again. This is the permission check at work: see {{ ref('permissions') }}.
  2. Add a role. On the Roles page add Coach at L2, then give it to an account with Give an account a role. That account can now open the user table, because L2 reaches the staff level. Change the role to L3 and it cannot. See {{ ref('roles') }}.
  3. Allow a website. On the CORS page add https://pages.example.org and Save. A request carrying that Origin header now gets the CORS headers back. Reset and it is gone. See {{ ref('cors') }}.

Each change is logged on its page under Recent changes, with who made it.

{% endcall %} {{ topic("Run the tests") }} {% call section("Running the tests") %} {% call code() %}pip install pytest python -m pytest tests{% endcall %}

pytest is not in requirements.txt, because the running app does not need it. The tests use a throwaway database and a fixed settings set, never the .env or instance/. One test (test_catalog_matches_code) imports the grading module, which needs pandas and scikit-learn. Both are in requirements.txt, so pip install -r requirements.txt installs them; in an environment set up before they were added, that single test fails and everything else passes. More in {{ ref('testing') }}.
